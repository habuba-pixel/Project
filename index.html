Going live on your own site

  1. Real satellite Earth. The globe already requests NASA's Blue Marble image from NASA GIBS. This preview's security sandbox blocks outside images, so you see a drawn Earth here. On Vercel or GitHub Pages the real image loads with no code change.
  2. Real local data. When you pick a place, the page calls the NASA POWER API for that point: temperature T2M, rainfall PRECTOTCORR, wind WS10M, 1981 to last year. If it answers, the Estimate badges flip to Live NASA.
  3. Country borders load from the open-source ECharts world map. If that fails, the globe falls back to a built-in outline.
  4. Sea level and Greenland: download the GMSL and Greenland mass files from NASA PO.DAAC (free Earthdata login) and paste the yearly values into the SEA and GL arrays.

How a trend gets confirmed

  1. Sen's slope gives the rate: the median of every pairwise slope, so one extreme year cannot drag it.
  2. Mann-Kendall test checks whether rises outnumber falls by more than chance. "Confirmed" needs p < 0.05.
  3. Time of emergence is the first year the trend line leaves the ±2σ band of year-to-year noise.
  4. Forecast extends the last 25 years' rate to 2050, with a band that widens with distance. It is a trend extrapolation, not a climate model run.
  5. Cherry-pick alarm fires for windows under 15 years or when the start year flips the trend's sign.
